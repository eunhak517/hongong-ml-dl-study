# 05-3. 트리의 앙상블

여러 결정 트리의 예측을 결합하는 랜덤 포레스트와 엑스트라 트리, 트리를 순서대로 추가하는 그레이디언트 부스팅 계열을 비교한 실습입니다.

- 실습 노트북: [`05_03_tree_ensemble.ipynb`](05_03_tree_ensemble.ipynb)
- 입력 특성: `alcohol`, `sugar`, `pH`
- 타깃: `class`
- 배깅 계열: `RandomForestClassifier`, `ExtraTreesClassifier`
- 부스팅 계열: `GradientBoostingClassifier`, `HistGradientBoostingClassifier`, `XGBClassifier`, `LGBMClassifier`

---

## 전체 흐름

```text
와인 데이터 준비
→ 랜덤 포레스트 교차 검증
→ 특성 중요도와 OOB 점수 확인
→ 엑스트라 트리와 비교
→ 그레이디언트 부스팅 비교
→ 히스토그램 기반 부스팅과 순열 중요도 확인
→ XGBoost·LightGBM 비교
```

## 모델별 결과

| 모델 | 평균 훈련 정확도 | 평균 검증 정확도 |
|---|---:|---:|
| 랜덤 포레스트 | `0.9974` | `0.8905` |
| 엑스트라 트리 | `0.9975` | `0.8888` |
| 그레이디언트 부스팅 기본 | `0.8881` | `0.8720` |
| 그레이디언트 부스팅 조정 | `0.9465` | `0.8780` |
| 히스토그램 그레이디언트 부스팅 | `0.9322` | `0.8801` |
| XGBoost | `0.9572` | `0.8782` |
| LightGBM | `0.9358` | `0.8801` |

히스토그램 기반 그레이디언트 부스팅의 최종 테스트 정확도는 `0.8723`입니다.

## 1. 랜덤 포레스트

랜덤 포레스트는 서로 다른 결정 트리를 여러 개 만들고 분류 결과를 합칩니다.

각 트리는 다음 두 가지 무작위성을 가집니다.

1. 훈련 샘플을 중복 허용으로 뽑는 부트스트랩 샘플
2. 노드마다 전체 특성 중 일부만 분할 후보로 사용

```python
rf = RandomForestClassifier(
    n_jobs=-1,
    random_state=42
)

scores = cross_validate(
    rf,
    train_input,
    train_target,
    return_train_score=True,
    n_jobs=-1
)
```

```text
평균 훈련 정확도: 0.9974
평균 검증 정확도: 0.8905
```

한 개의 트리가 훈련 데이터를 세세하게 외우더라도, 서로 다른 여러 트리의 결과를 합치면 한 트리의 과대적합 영향을 줄일 수 있습니다.

### 특성 중요도

```python
rf.fit(train_input, train_target)
print(rf.feature_importances_)
```

| 특성 | 중요도 |
|---|---:|
| `alcohol` | `0.2317` |
| `sugar` | `0.5004` |
| `pH` | `0.2679` |

5-1의 단일 결정 트리보다 중요도가 세 특성에 더 고르게 분산됐습니다.

### OOB 점수

```python
rf = RandomForestClassifier(
    oob_score=True,
    n_jobs=-1,
    random_state=42
)
```

부트스트랩 샘플에 선택되지 않은 데이터를 OOB 샘플이라고 합니다. 해당 트리가 보지 않은 OOB 샘플을 이용해 별도 검증 세트와 비슷한 평가를 할 수 있습니다.

```text
OOB 정확도: 0.8934
```

교차 검증 평균 `0.8905`와 비슷합니다.

## 2. 엑스트라 트리

엑스트라 트리도 여러 결정 트리를 합치지만 랜덤 포레스트보다 노드 분할에 더 큰 무작위성을 줍니다.

```python
et = ExtraTreesClassifier(
    n_jobs=-1,
    random_state=42
)
```

```text
평균 훈련 정확도: 0.9975
평균 검증 정확도: 0.8888
```

### 랜덤 포레스트와 엑스트라 트리의 차이

| 구분 | 랜덤 포레스트 | 엑스트라 트리 |
|---|---|---|
| 훈련 샘플 | 부트스트랩 샘플 | 기본적으로 전체 훈련 샘플 |
| 특성 선택 | 일부 특성만 후보 | 일부 특성만 후보 |
| 분할 기준 | 후보 안에서 좋은 분할 탐색 | 분할 기준을 무작위로 선택 |
| 공통점 | 여러 트리의 예측 결합 | 여러 트리의 예측 결합 |

> **이전 질문과 연결 — “랜덤 포레스트와 엑스트라 트리는 무엇이 다른가?”**  
> 둘 다 여러 트리를 합치는 앙상블이지만, 엑스트라 트리가 분할 기준에 더 큰 무작위성을 줍니다.

> **이전 질문과 연결 — “노드를 무작위로 분할한다는 것은 무슨 뜻인가?”**  
> 클래스를 아무렇게나 나눈다는 뜻이 아닙니다. 특성과 임계값을 모두 최적으로 찾는 대신 무작위로 뽑은 분할 후보를 사용한다는 뜻입니다.

> **이전 질문과 연결 — “결정 트리의 `splitter='random'`이 곧 엑스트라 트리인가?”**  
> 아닙니다. `splitter='random'`은 한 개의 결정 트리에 무작위 분할을 적용한 설정이고, `ExtraTreesClassifier`는 무작위성이 큰 트리를 여러 개 학습해 결과를 합치는 앙상블입니다.

### 특성 중요도

| 특성 | 중요도 |
|---|---:|
| `alcohol` | `0.2018` |
| `sugar` | `0.5224` |
| `pH` | `0.2757` |

## 3. 그레이디언트 부스팅

랜덤 포레스트와 엑스트라 트리는 여러 트리를 비교적 독립적으로 만듭니다. 그레이디언트 부스팅은 트리를 순서대로 추가하면서 앞선 모델이 부족했던 부분을 다음 트리가 보완합니다.

### 기본 설정

```python
gb = GradientBoostingClassifier(random_state=42)
```

```text
평균 훈련 정확도: 0.8881
평균 검증 정확도: 0.8720
```

### 트리 수와 학습률 변경

```python
gb = GradientBoostingClassifier(
    n_estimators=500,
    learning_rate=0.2,
    random_state=42
)
```

```text
평균 훈련 정확도: 0.9465
평균 검증 정확도: 0.8780
```

- `n_estimators`: 순서대로 추가할 트리 수
- `learning_rate`: 각 트리의 보정 결과를 반영하는 정도

트리 수와 학습률을 늘린 뒤 검증 점수는 높아졌지만 훈련·검증 점수 차이도 커졌습니다.

### 특성 중요도

| 특성 | 중요도 |
|---|---:|
| `alcohol` | `0.1589` |
| `sugar` | `0.6800` |
| `pH` | `0.1612` |

## 4. 히스토그램 기반 그레이디언트 부스팅

특성값을 여러 구간으로 묶은 뒤 분할을 탐색해 일반적인 그레이디언트 부스팅보다 빠르게 학습합니다.

```python
hgb = HistGradientBoostingClassifier(random_state=42)
```

```text
평균 훈련 정확도: 0.9322
평균 검증 정확도: 0.8801
최종 테스트 정확도: 0.8723
```

`cross_validate()`의 `test_score`는 각 폴드의 검증 점수입니다. `hgb.score(test_input, test_target)`이 최종 테스트 세트 점수입니다.

### 순열 중요도

순열 중요도는 특성 하나의 값을 무작위로 섞은 뒤 성능이 얼마나 감소하는지 측정합니다.

| 특성 | 훈련 세트 | 테스트 세트 |
|---|---:|---:|
| `alcohol` | `0.0888` | `0.0597` |
| `sugar` | `0.2344` | `0.2024` |
| `pH` | `0.0803` | `0.0490` |

훈련 세트와 테스트 세트 모두 `sugar`를 섞었을 때 정확도가 가장 크게 감소했습니다.

## 핵심 항목

| 항목 | 역할 |
|---|---|
| `RandomForestClassifier` | 부트스트랩 샘플과 일부 특성으로 여러 트리 학습 |
| `oob_score_` | OOB 샘플을 이용한 검증 정확도 |
| `ExtraTreesClassifier` | 무작위 분할이 강한 여러 트리 학습 |
| `GradientBoostingClassifier` | 앞선 모델의 부족한 부분을 순차적으로 보완 |
| `HistGradientBoostingClassifier` | 특성값을 구간으로 묶어 빠르게 부스팅 |
| `permutation_importance` | 특성을 섞었을 때의 성능 감소량 측정 |
| `XGBClassifier` | XGBoost 분류 모델 |
| `LGBMClassifier` | LightGBM 분류 모델 |

## 정리

```text
랜덤 포레스트
→ 서로 다른 여러 트리를 독립적으로 학습해 결과 결합

엑스트라 트리
→ 분할 기준에 더 큰 무작위성을 주고 결과 결합

그레이디언트 부스팅
→ 트리를 순서대로 추가하며 앞선 오차 보완

히스토그램 기반 부스팅
→ 특성값을 구간으로 묶어 빠르게 분할 탐색
```

핵심은 여러 트리가 **서로 다른 판단을 하게 만든 뒤 결과를 합치거나, 앞선 트리의 부족한 부분을 다음 트리가 보완하게 만드는 것**입니다.
